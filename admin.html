Réglages de la récupération automatique

Une seule fois : installe le script Google sur la feuille des réponses (voir README, « Récupération automatique »), puis colle ici l’adresse de son application web et le code secret. Ils restent sur cet appareil.

Sinon, à la main — dans Google Forms : onglet Réponses → Afficher dans Sheets ; puis dans la feuille : Fichier → Télécharger → Valeurs séparées par des virgules (.csv). Choisis ensuite ce fichier ici (il reste sur ton appareil, rien n’est envoyé).

Listes des oiseaux par année

Au 1er janvier, la liste de l’année qui se termine est archivée automatiquement : c’est fait à la première ouverture de cette page dans la nouvelle année, à partir de l’historique GitHub, donc c’est bien la liste du 31 décembre. La nouvelle année démarre avec la même liste. Tu peux ensuite la modifier dans l’éditeur, ou reprendre une liste archivée comme référence de l’année.
